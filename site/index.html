Your coding agent, with a peon'speasant's work ethic.

Agent Warcraft plays Warcraft III voice lines when Claude Code, Codex, or Gemini CLI does something you should hear about. You get "Ready to work" at the start, "Work complete" when a turn ends, and "We're under attack!" when an approval is for rm -rf. When your usage runs out, the advisor says what every RTS player already knows: we need more gold.

Destructive-command alarm

Our town is under attack.

When an approval is for something you cannot take back, the cue changes. Recursive force deletes, force pushes, hard resets, dropped tables, mkfs, dd, and their PowerShell cousins all sound the alarm instead of the ordinary prompt.

It is a louder cue, not a safety check. The hook never blocks, approves, logs, or stores the command; only a yes/no flag leaves it.

agent wants to run:
$ git push --force origin main
allow? [y/n]

Usage alarms

We need more gold.

Claude Code reports why a turn failed. Rate limits, billing errors, and accounts on hold play the gold line. Hitting the output token limit plays the lumber line. An optional status-line meter shows how much of your tightest limit is left, and the advisor warns you once when the mine runs low.

Install

Two commands. Ready to work.

Run these in your terminal. Node.js 22+ and a local audio player are required. Restart your agent after installation.

Claude Code

claude plugin marketplace add mitchtech/agent-warcraft
claude plugin install warcraft@agent-warcraft

Codex

codex plugin marketplace add mitchtech/agent-warcraft
codex plugin add warcraft@agent-warcraft

Gemini CLI

gemini extensions install https://github.com/mitchtech/agent-warcraft

Review and trust the sound hooks in Codex's hook settings. Running Agent Navi or Agent Johnny 5 too? Enable one per host so a fairy, a robot, and a peon do not talk over each other. Other agents use the standalone event interface.

Sound controls
agent-warcraft status
agent-warcraft faction alliance
agent-warcraft mute prompt_submitted
agent-warcraft unmute subagent_started
agent-warcraft preset attention
agent-warcraft unmute all

Or ask your agent to "switch the peon to Alliance" or "mute the peon" through the bundled control skill. Global mute preserves your event preferences.
