# Preview images

The waveform GIFs, social card, README banner, and touch icon are generated by
[`scripts/build-assets.py`](../../scripts/build-assets.py) from the committed
clips in [`audio/`](../../audio). The waveforms depict *Warcraft III* audio,
whose rights remain with Blizzard Entertainment; see the
[audio rights notice](../../audio/NOTICE.md).
